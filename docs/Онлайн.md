# ONLINE_CONTEXT — Контекст разработки онлайн-режима Darts Trainer

Этот файл — дополнение к основному AI_CONTEXT. Здесь описана вся история, архитектура и планы по разработке онлайна. Прочитай его целиком, прежде чем вносить изменения.

---

## 1. СТАТУС ПРОЕКТА (Онлайн)
На данный момент **полностью готова визуальная часть (UI) онлайна** и **развернут сервер с базой данных**. Реального обмена данными между приложением и сервером пока нет (в приложении все еще работает симуляция), но инфраструктура готова. Следующий шаг — подключить код Android к серверу.

---

## 2. ИНФРАСТРУКТУРА И СЕРВЕР
*   **Хостинг:** Российский провайдер **Xorek.Cloud**. Куплен тариф (NL-E-4): 2 vCPU, 4 ГБ RAM, 60 ГБ SSD.
    *   **IP-адрес:** `179.236.147.116`
    *   **Операционная система:** Ubuntu 22.04.
    *   **Доступ:** Через программу **Termius** (по SSH, под root).
    *   *Примечание:* На этом же сервере уже работает Telegram-бот для игры в шашки (на Python, работает как служба `systemd`, порты не конфликтуют).
*   **Бэкенд (серверная часть):** **PocketBase** (версия 0.23.4).
    *   Расположен в папке `/root/pocketbase`.
    *   Запускается вручную командой: `./pocketbase serve --http="0.0.0.0:8090"`.
    *   Админ-панель доступна по адресу: `http://179.236.147.116:8090/_/`
*   **База данных:** Создана коллекция (таблица) `players` со следующими полями:
    *   `id` (системное)
    *   `nickname` (Text)
    *   `level` (Number)
    *   `created` / `updated` (системные)
    *   *Настроены API Rules:* разрешено создание и чтение записей (для матчмейкинга), остальное — только для админа.

## 3. БИЗНЕС-ЛОГИКА И МОНЕТИЗАЦИЯ (Планы)
*   Приложение бесплатное.
*   **RuStore:** Планируется выложить усеченную версию (без онлайна).
*   **Сайт:** Полная версия (с онлайном) будет распространяться с нашего сайта на сервере.
*   **Монетизация:** Добровольные донаты или минимальная подписка (20-30 руб/мес) через сторонние сервисы на сайте.

## 4. АРХИТЕКТУРА ОНЛАЙНА (Где что лежит)

**`ui/online/OnlineLobbyScreen.kt`**
*   Интерфейс лобби.
*   Хранит настройки в SharedPreferences.
*   Позволяет задать никнейм и уровень.
*   Окно настройки поиска (выбор уровней, времени).
*   Анимация поиска (глобус + лупа) с таймером.
*   Окно результата поиска.

**`ui/online/OnlineChatOverlay.kt`**
*   Универсальный компонент чата (развернутый и свернутый вид, счетчик непрочитанных).

**`ui/game501/Game501Screen.kt`** и **`ui/cricket/CricketGameScreen.kt`**
*   Встроен чат (только если `isOnlineGame = true`).
*   В Крикете шапка переделана под макет (чат слева, кнопки справа).
