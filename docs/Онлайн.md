# ONLINE_CONTEXT — Контекст разработки онлайн-режима Darts Trainer

Этот файл — дополнение к основному AI_CONTEXT. Здесь описана вся история, архитектура и планы по разработке онлайна. Прочитай его целиком, прежде чем вносить изменения.

---

## 1. СТАТУС ПРОЕКТА (Онлайн)
**Онлайн-режим для игры 501 полностью готов и стабилен.** Реализована связь через сервер (Handshake), массовая рассылка (Broadcast), одиночные приглашения, живой чат, розыгрыш Булла, защита от зависаний, система друзей (локальная), а также **глобальные приглашения** (приходят в любом разделе приложения).
**Крикет по сети пока не синхронизируется** (при запуске играет локально с ботом под именем соперника).

---

## 2. ИНФРАСТРУКТУРА И СЕРВЕР
*   **Хостинг:** **Xorek.Cloud**. Тариф NL-E-4 (2 vCPU, 4 ГБ RAM). IP: `179.236.147.116`, ОС: Ubuntu 22.04.
*   **Бэкенд:** **PocketBase** (версия 0.23.4). Настроен как служба `systemd`, работает 24/7, добавлен в автозапуск (`systemctl enable pocketbase`).
*   **Админ-панель:** `http://179.236.147.116:8090/_/`
*   **База данных (Коллекции):**
    *   `players`: id, nickname (уникальный), level.
    *   `invites`: from_user, to_user, status (pending/accepted), match_id.
    *   `game_states`: match_id, game_type, state_json, last_updated, player1_id, player2_id.
    *   `messages`: match_id, from_user, text (для чата).
*   **Очистка БД:** На сервере настроен `cron` (задача в `/root/cleanup_games.sh`), который каждый час удаляет игры из `game_states` старше 3 часов.

## 3. АРХИТЕКТУРА И ЛОГИКА

### Сеть (`OnlineNetworkManager.kt`)
*   `registerPlayer`: Умная регистрация (PATCH/POST).
*   `findMatchingOpponents`, `sendBroadcastInvites`, `sendSingleInvite`, `cancelMatchSearch` — логика приглашений.
*   `upsertGameState` / `getGameState` / `deleteGameState` — синхронизация состояния игры.
*   `sendChatMessage` / `getChatMessages` — работа с чатом.

### Лобби (`OnlineLobbyScreen.kt`)
*   Опрос сервера на входящие приглашения (каждые 3 сек, только когда экран лобби активен).
*   Окно настройки поиска, окно ожидания (30 сек), окно «Устарело».
*   **Друзья**: Локальный список (сохранен в `FriendsStorage.kt` в SharedPreferences телефона). В диалоге «Играть с другом» есть кнопка «Список друзей» (выпадающее меню). Там можно удалить друга (иконка корзины), добавить нового (с заметкой) или нажать на друга для отправки приглашения.
*   **Защита ников**: Запрещено использовать никнеймы, содержащие `adm` или `адм` в любом регистре.

### Игра 501 (`Game501Screen.kt`)
*   **Булл**: При старте онлайн-игры включается фаза `isBullPhase`. Кнопки «Мимо» (серая), «Зеленый», «Красный». Автостарт через 2 секунды после определения победителя.
*   **Синхронизация**: Отправка стейта при любом изменении (`upsertGameState`). Чтение — каждые 1.5 сек.
*   **Защита от зависаний**: При отправке хода ставится флаг `isSendingMove` (чтение блокируется на 0.8 сек). Защита от отката (сравнение сетов/легов/дротиков).
*   **Имена**: Твое имя всегда слева (зеркалится в зависимости от `onlinePlayerIndex`).
*   **Предыдущий набор**: В шапке отображается, сколько выбил соперник в прошлый раз.
*   **Кнопка Undo**: Работает в онлайне. Возвращает ход и очки, отправляет обновленный стейт.
*   **Чат**: Живой чат (каждые 2.5 сек проверка новых сообщений). Свои сообщения синие справа, чужие белые слева.

### Глобальные приглашения (`MainActivity.kt`)
*   В `MainActivity` висит «Глобальный радар» (`LaunchedEffect`).
*   Он проверяет входящие приглашения каждые 3 секунды, если пользователь **не** в лобби и **не** в игре 501.
*   Если приходит приглашение, поверх любого экрана (тренировки, статистики) выскакивает окно.
*   При нажатии «Принять» тренировка автоматически сохраняется, и игра начинается сразу (Булл).
