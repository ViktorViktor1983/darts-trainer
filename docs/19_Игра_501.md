# 19. Игра 501

Основной игровой режим. Матч двух игроков или игрока против бота. Цель — первым дойти от 501 до нуля.

## Экран настройки партии

Перед началом игры настраиваются параметры.

### Игроки

- Слот 1 — по умолчанию игрок (из анкеты).
- Слот 2 — бот или второй игрок.

### Настройки партии

- Состав: личный / пара / микст.
- Формат: леги / сеты.
- Закрытие: Double Out / Double In-Out.
- Количество легов / сетов: настраивается.
- Кто начинает: игрок 1 / игрок 2 / розыгрыш Булла.
- Максимум дротиков на лег: 9 (стандарт) или другой.

### Игра с ботом

- Выбор бота — с именем и уровнем.
- Время броска бота — 1 / 3 / 5 секунд.

## Боты с именами

Не «Бот 1, Бот 2», а имена с диапазоном среднего набора. Привязка к 16 уровням.

| Уровень | Имя бота | Средний набор |
|---|---|---|
| 1–2 | Новичок | 30–40 |
| 3–4 | Ученик | 40–50 |
| 5–6 | Любитель | 50–60 |
| 7–8 | Разрядник | 60–70 |
| 9–10 | Опытный | 70–80 |
| 11–12 | Сильный | 80–90 |
| 13–14 | КМС | 90–100 |
| 15–16 | Чемпион | 100+ |

В списке — имя + уровень. Например: «Любитель (50–60)».

## Розыгрыш Булла

Перед первой игрой — розыгрыш, кто начинает. Показывается диалог с вариантами:

- КРАСНЫЙ (50)
- ЗЕЛЁНЫЙ (25)
- МИМО (0)

Игрок и бот «бросают». Если оба попали в разные — побеждает тот, у кого больше. Если одинаково — переигровка.

Цвета как в дартсе: красный центр = 50, зелёное кольцо = 25.

## Экран игры

### Верхняя панель

- Имя игрока 1 — активный подсвечивается.
- Счёт легов (например, 0 : 0).
- Имя игрока 2.

### Табло

- Остаток игрока 1 — крупно.
- Остаток игрока 2 — крупно.
- Средний набор — под остатком каждого игрока.
- История последних подходов — что было в прошлых бросках.
- Метка Булла — точка рядом с игроком, который сейчас бросает.

### Область ввода

Строка 1 — быстрые кнопки (11 штук):

- Стандартный набор: 140, 100, 95, 85, 81, 120, 60, 57, 45, 41, 26.
- Автообновление раз в 3 игры — под персональные суммы игрока.

Строка 2 — кнопки управления:

- Остаток — ввести остаток напрямую.
- Лег — быстрое закрытие лега.
- aOK — автоподтверждение с таймером.

Цифровая клавиатура:

- Цифры 0–9.
- Кнопка стереть.
- Стрелка влево — «Ход назад» (отмена последнего ввода).
- OK — подтвердить.

## Ввод за подход

### Основной способ

Игрок вводит сумму за подход (60, 100, 140) и нажимает OK.

### Кнопка «Остаток»

Игрок вводит остаток напрямую — приложение само считает сумму за подход.

Пример:
- Остаток был 120.
- Игрок бросил: 60 + 20 + мимо = 80.
- Осталось 40.
- Вводит 40 → нажимает «Остаток».
- Приложение: 120 − 40 = 80 за подход.

### Кнопка «Лег»

Игрок закрыл лег. Нажимает «Лег» — вместо ввода суммы.

### АвтоОК

Настраивается: 3 / 5 / 10 секунд или выключен.
Если игрок не нажал OK — подтверждается автоматически.
Защита от случайного ввода: виден последний набор + кнопка «Ход назад».

## Диалоги после подхода

### Если остаток меньше 50

Показывается диалог: «Сколько было попыток поразить удвоение?»

Варианты: 0 / 1 / 2 / 3

- 0 — не успел выйти на дабл.
- 1 — бросил один, попал.
- 2 — бросил два, попал вторым.
- 3 — бросил три, попал третьим.

### Если лег закрыт

Показывается диалог: «Сколько дротиков ушло на закрытие?»

Варианты: 1 / 2 / 3 / Отмена

## Уведомление о закрытии лега

Когда игрок закрыл лег — показывается диалог на затемнённом фоне:

Содержимое:
- Иконка (мишень или галочка).
- Заголовок «ЛЕГ ЗАКРЫТ!».
- Имя игрока.
- Количество дротиков.
- Текущий счёт.
- Кнопка «Продолжить».

Закрывается:
- Кнопкой «Продолжить».
- Автоматически через 5 секунд.

## Сообщения о переборе и нулевом подходе

### Перебор

Если игрок ввёл сумму больше остатка (или остаток стал 1):

- Сообщение «ПЕРЕБОР» по центру экрана.
- Длительность: 1,5 секунды.
- Остаток не меняется.
- Ход переходит сопернику.

### Нулевой подход

Если игрок ввёл 0 вручную:

- Сообщение «МИМО» по центру экрана.
- Длительность: 1,5 секунды.
- Остаток не меняется.
- Ход переходит сопернику.

## Статистика после матча

### Счёт

- Счёт легов / сетов.
- Победитель.

### Основные показатели

- Средний набор — за весь матч.
- Первые 9 — средний набор за первые 3 подхода.
- Набор без закрытия — средний набор на подходах без выхода на дабл.
- Лучший лег — за сколько дротиков.
- Худший лег — за сколько дротиков.
- Среднее дротиков на закрытие.

### Закрытия

- Макс. закрытие — самый крупный чекаут.
- Закрытия 100+ — сколько раз закрыл чекаут 100+.
- Удвоения — процент попадания (попытки / попадания).
- Брейк — победа в леге соперника.

### Разбивка по наборам

Категории: 20−, 20+, 40+, 60+, 80+, 100+, 140+.

### Распределение легов

Победы по скорости: 9–12, 13–15, 16–18, 19–21, 22+.

### История игры

Список всех подходов с раскладкой. Например:

441 → 60
381 → 100
281 → 79
202 → 60
142 → 95
47 → 47
X1 → (19)

### Наше уникальное

- Слабые удвоения — какие даблы хромают в этом матче.
- Прогресс — сравнение с прошлыми матчами.

## Автообновление быстрых кнопок

- Стандартный набор: 140, 100, 95, 85, 81, 120, 60, 57, 45, 41, 26.
- Раз в 3 игры приложение анализирует, какие суммы за подход игрок набирает чаще всего.
- 11 самых частых становятся быстрыми кнопками.

Хранение — в базе данных Room, вместе с историей игр и статистикой.

## Что НЕ используем

- Кнопка «Бюст» — не нужна, перебор определяется автоматически.
- Кнопка «Мимо» — вводится цифрой 0.
- Отдельная кнопка 180 — убрана из быстрых.
- Диалог броска бота по дротикам — не нужен, игрок смотрит только на итоговый набор.
- Уведомление «закрыл лег» с крестиком — заменено на кнопку «Продолжить» + авто-закрытие через 5 секунд.
- Пьяный бот — это явный признак копирования, не берём.

## Что важно

- Ввод быстрый. Не отвлекает от игры.
- Статистика точная. Диалоги про удвоения и дротики на закрытие дают полную картину.
- Не копируем чужое. Свой дизайн, свои решения.
- Юмор — свой. Если добавлять — что-то оригинальное.
- Всё сохраняется. История игр, статистика, топ-11 сумм — в Room.
