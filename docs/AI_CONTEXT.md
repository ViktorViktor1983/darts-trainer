Этот файл — краткая инструкция для любого ИИ (Claude, ChatGPT, Gemini и т.д.),

## 1. ПРОЕКТ

**Название:** Darts Trainer (Персональный тренер по дартсу)
**Платформа:** Android, нативный Kotlin + Jetpack Compose + Room
**Репозиторий:** github.com/ViktorViktor1983/darts-trainer (ветка main)
**Пакет:** com.lodkin.dartstrainer
**Сборка:** Gradle Kotlin DSL (build.gradle.kts)
**CI:** GitHub Actions — APK собирается автоматически после каждого коммита (3–5 минут)

Приложение для игры в дартс с ботами. 6 игровых режимов, статистика,
настройки игрока, полноценный тренировочный раздел с ИИ-планировщиком,
система рекордов, сдача нормативов, свободный режим с рулеткой,
раздел «О программе».

**Автор:** Виктор Лодкин (ViktorViktor1983).

**Второе приложение (не трогаем):**
Darts Checkout — справочник чекаутов.
Репозиторий: github.com/ViktorViktor1983/DARTS-checkout

## 5. АРХИТЕКТУРА И ЛОГИКА

### Периоды
С момента последнего экзамена. При сдаче экзамена (`clearStatisticsAfterNormatives`) данные не удаляются, а начинается новый период (`periodId + 1`). Данные проблемных секторов считаются только за текущий период.

### Статистика и цветные плашки
- Для каждой дисциплины (501, Крикет, Сектор 20, Большой раунд, Набор очков, 3 Кругосветки) берутся средние значения за текущий период.
- Сравниваются с нормативами **стартового уровня** (из анкеты или после экзамена) через `DartsNorms.getStatus()`.
- Если значение ниже нормы → красный, в норме → жёлтый, выше нормы → зелёный, нет данных → серый.
- В `DetailedStatsScreen` все дисциплины сортируются: красные наверху, затем жёлтые, зелёные, серые.

### Проблемные сектора
- Считаются только по 3 Кругосветкам, только за текущий период.
- Минимум 5 игр по каждому параметру, иначе «Мало данных».
- Отклонение от среднего >25% → жёлтый, >50% → красный, топ-3 худших.
- Показываются в `DisciplineStatsScreen` (блок «ДОПОЛНИТЕЛЬНЫЕ»), `DetailedStatsScreen` (счётчики), и в `ProblemSectorsScreen` (для отработки).

### Тренировка
1. **Порядок блоков:** Разминка ➔ Психология ➔ Основной блок ➔ Силовой блок ➔ Итоги.
2. **Разминка:** 12 упражнений на мышцы (4 группы: шея, плечи, кисти, ноги) + 3 с дротиками. Выбираются случайно по одному из каждой группы. Таймер: 40 секунд для мышц, 2 минуты для дротиков. Перед каждым — 5-секундный превью «ПРИГОТОВЬСЯ».
3. **Психология:** 8 упражнений по 3 штуки. Без вибрации. «Один дротик» на таймере.
4. **Основной блок:** Без кругового таймера (только общий таймер тренировки).
5. **Силовые:** 9 упражнений по 3 штуки (с учётом инвентаря). Круговой таймер включён.
6. **Таймер тренировки:** Идёт в обратном порядке. За 5 минут выскакивает окно. Может уходить в минус.

### Экзамен (НОВАЯ ЛОГИКА)
- **5 дисциплин:** 501 (до 3 побед), Крикет (до 3 побед), Сектор 20, Большой раунд, Набор очков.
- **Подсчёт уровня:**
  1. Уровень по 501 (через PPR) + уровень по Крикету (через MPR) = среднее (округление по математике).
  2. Уровень по Сектору 20 + БР + Набор = среднее (округление по математике).
  3. Среднее между двумя комплексами (округление по математике).
- **Логика с понижением:**
  - Если новый уровень выше → повышаем, счётчик неудач = 0.
  - Если равен → подтверждаем, счётчик = 0.
  - Если ниже → счётчик неудач +1, уровень **не понижается**.
  - Если счётчик неудач ≥ 2 → понижаем уровень на 1, счётчик = 0.
- **Обнуление:** после любого экзамена статистика обнуляется, начинается новый период.
- **Результат:** показывается диалог с текстом (повышение/подтверждение/предупреждение/понижение).

### Свободная тренировка
- Переключатель «РУЛЕТКА» / «ВЫБРАТЬ САМОМУ» (сохраняется в SharedPreferences).
- Режим рулетки: «Без повторов» (убирает уже сыгранные игры).
- Режим «Выбрать самому»: список всех упражнений, включая «Проблемные сектора».

### Незавершённые игры
- Тренировочные незавершённые партии → ID в `TrainingUnfinishedStorage`, отображаются в `DetailedStatsScreen`.
- Свободные незавершённые партии → в `StatsMenuScreen`.
- При возобновлении тренировочной партии — `isResumingFromStats = true`, кнопка «Назад» возвращает в статистику.

### Онлайн-игра
**Полный контекст в `ONLINE_CONTEXT.md`.** Готова только визуальная часть. Реального подключения нет.

### Крикет (Американский)
- **Кнопки секторов:** 1 — зелёная «1», 2 — жёлтая «2», 3 — красная «3», >3 — фиолетовая с числом (4, 5, 6...), «мертвая» — чёрная.
- **Шапка:** «КРИКЕТ АМЕРИКАНСКИЙ», кнопки «НАЗАД», СЕТ/ЛЕГ.

### Чат (Онлайн)
- Белый фон, крестик не уезжает за клавиатуру (высота 480.dp).
- Автосворачивание после отправки.
- Свернутый вид — последние 3 сообщения, счётчик непрочитанных.
