## 1. ПРОЕКТ

**Название:** Darts Trainer (Персональный тренер по дартсу)
**Платформа:** Android, нативный Kotlin + Jetpack Compose + Room
**Репозиторий:** github.com/ViktorViktor1983/darts-trainer (ветка main)
**Пакет:** com.lodkin.dartstrainer
**Сборка:** Gradle Kotlin DSL (build.gradle.kts)
**CI:** GitHub Actions — APK собирается автоматически после каждого коммита (3–5 минут)

Приложение для игры в дартс с ботами. 6 игровых режимов, статистика,
настройки игрока, полноценный тренировочный раздел с ИИ-планировщиком,
система рекордов, сдача нормативов, свободный режим с рулеткой,
раздел «О программе».

**Автор:** Виктор Лодкин (ViktorViktor1983).

**Второе приложение (не трогаем):**
Darts Checkout — справочник чекаутов.
Репозиторий: github.com/ViktorViktor1983/DARTS-checkout

## 5. АРХИТЕКТУРА И ЛОГИКА

### Периоды
С момента последнего экзамена. При сдаче экзамена (`clearStatisticsAfterNormatives`) данные не удаляются, а начинается новый период (`periodId + 1`).

### Статистика
Собирается в `detailsJson`. В `DisciplineStatsScreen` строятся графики.
**Проблемные сектора:** После 5 Кругосветок программа подсвечивает сектора (желтым/красным), где точность ниже средней.

### Тренировка (НОВАЯ ЛОГИКА)
1. **Порядок блоков:** Разминка ➔ Психология ➔ Основной блок ➔ Силовой блок ➔ Итоги.
2. **Таймер:** Идет в обратном порядке.
3. **Окно за 5 минут:** Когда остается 5 минут, выскакивает `TimeUpDialog` с кнопками «К силовым» и «Доиграть».
4. **Таймер в минус:** Если игрок нажимает «Доиграть», таймер уходит в минус (например, `-01:15`). Игрок может запускать новые игры бесконечно.
5. **Экран итогов:** Кнопка «ПЕРЕЙТИ К СЛЕДУЮЩЕМУ БЛОКУ» переводит на следующий блок (или завершает тренировку).
6. **Свободные игры:** Игрок может играть в любые игры из списка "Рекомендовано сыграть" прямо с экрана итогов.

### Психология и Силовые
- **Психология:** 8 упражнений. Даются по 3 штуки.
- **Силовые:** 9 упражнений. При входе в блок выскакивает `InventoryDialog` (выбор гантелей/резинки).

### Онлайн-игра
**Полный контекст по онлайну вынесен в отдельный файл `ONLINE_CONTEXT.md`.**
Кратко: используется российский хостинг Cloud.ru, бэкенд на PocketBase. Сейчас готова вся визуальная часть (лобби, поиск, чат в играх 501 и Крикет), но реального подключения к серверу пока нет.

### Особенности Крикета (Американский)
- **Цвета и цифры на кнопках секторов:**
  - 1 попадание — зеленая, «1».
  - 2 попадания — желтая, «2».
  - 3 попадания — красная, «3».
  - Больше 3 (набор очков, пока соперник не закрыл) — фиолетовая, показывает реальное число («4», «5», «6»).
  - Сектор закрыт обоими игроками («мертвый») — черная кнопка, цифры остаются у каждого свои.
- **Шапка:** Золотой заголовок «КРИКЕТ АМЕРИКАНСКИЙ», кнопка «НАЗАД» и СЕТ/ЛЕГ.

### Чат (Онлайн)
- Работает в 501 и Крикете.
- **Развернутый вид:** Белый фон, крестик для закрытия всегда на виду (высота чата ограничена 480.dp). Кнопка «Сообщение...» и кнопка отправки.
- **Автосворачивание:** После нажатия кнопки «Отправить» чат автоматически закрывается, возвращая игрока к игре.
- **Свернутый вид:** Показывает последние 3 сообщения. Последнее сообщение может занимать 2-3 строки, чтобы текст был виден. Есть счетчик непрочитанных.
