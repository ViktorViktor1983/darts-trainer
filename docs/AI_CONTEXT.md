# AI_CONTEXT — шпаргалка для нового ИИ-ассистента

Этот файл — краткая инструкция для любого ИИ (Claude, ChatGPT, Gemini и т.д.),
который подхватит работу над проектом Darts Trainer. Прочитай целиком,
прежде чем задавать вопросы.

## 1. ПРОЕКТ

**Название:** Darts Trainer (Персональный тренер по дартсу)
**Платформа:** Android, нативный Kotlin + Jetpack Compose + Room
**Репозиторий:** github.com/ViktorViktor1983/darts-trainer (ветка main)
**Пакет:** com.lodkin.dartstrainer
**Сборка:** Gradle Kotlin DSL (build.gradle.kts)
**CI:** GitHub Actions — APK собирается автоматически после каждого коммита (3–5 минут)

Приложение для игры в дартс с ботами. 6 игровых режимов, статистика,
настройки игрока, полноценный тренировочный раздел.

**Автор:** Виктор Лодкин (ViktorViktor1983).

Репозиторий: github.com/ViktorViktor1983/DARTS-checkout

## 2. КАК ОБЩАТЬСЯ С АВТОРОМ

Автор — не программист, изучает Kotlin/Android по ходу дела.
Правила:

- Объясняй простыми словами, без жаргона.
- **ОДИН ФАЙЛ — ОДНО СООБЩЕНИЕ.** Это железное правило.
  Не давать 2+ файлов в одном ответе. Если нужно обновить 2 файла —
  сначала один, потом автор напишет «Готово», потом второй.
- **Формат выдачи кода:**
  1. Путь к файлу (отдельным блоком)
  2. Действие: «создать новый» / «заменить целиком»
  3. Сам код целиком одним блоком
- Давай код **целиком**, не разбивай на части.
- Не переписывай без нужды. Меняем минимально.
- Если автор прислал не тот файл — вежливо скажи и попроси нужный.

## 8. ТРЕНИРОВОЧНЫЙ РАЗДЕЛ — КОНЦЕПЦИЯ

### Суть
Не инструмент, а тренер. Даёт конкретную программу на день, подстраивается
под игрока, ведёт от новичка до мастера.

### ЧЕТЫРЕ параметра игрока
1. **Набор очков** — источники: 501 (первые 9), Сектор 20/19, Набор очков
2. **Точность в сектор** — Кругосветка-Сектора, Большой раунд
3. **Удвоения** — 501 (удвоения матча), Кругосветка-Удвоения
4. **Утроения** — Кругосветка-Утроения, Большой раунд

Что НЕ даёт параметров: Крикет (только разнообразие).

### Логика уровня — ДВА КОМПЛЕКСА
- Комплекс 1: 501 (PPR). Уровень по таблице ботов.
- Комплекс 2: упражнения. Среднее 4 параметров, округление ВВЕРХ.
- Итоговый = МАКСИМУМ из двух комплексов.
- Расхождение = сигнал психологии.

### Потенциал
= максимум из уровней по 4 параметрам.

### Экзамен
Каждые 10 тренировок. Внутри цикла уровень не меняется.

### Тренды
3 последние тренировки. Растёт / падает / стоит.

### Средний темп (в планах)
Среднее время выполнения упражнения по последним 5 тренировкам.
Программа использует его вместо фиксированных минут.

### Правило 3 часов (в планах)
Если игрок вышел из тренировки, состояние сохраняется.
Возврат в течение 3 часов → диалог «Продолжить / Начать заново».
Больше 3 часов → состояние сбрасывается.

### Структура тренировки
- Разминка (4 фазы)
- Основная часть (6 упражнений)
- Психология (3 упражнения)
- Силовая (5 упражнений)

### Режимы тренировок
По расписанию / Гибкий / Свободный.

### Отложенные даблы
Возвращаются в начале следующей тренировки.

### Свободная игра vs Тренировка
Раздельная статистика. Сравнение = индикатор психологического давления.

### Адаптивная сложность ботов (в планах)
- Первая партия: бот на 1 уровень слабее игрока.
- Следующая тренировка: выиграл → +1, проиграл → −1.
- Уровень бота хранится между тренировками.

### Диагностическое первое упражнение (в планах)
Для не-новичков первое упражнение основной части — диагностическое
(Сектор 20 / Набор очков / Большой раунд), по нему уточняется уровень.

### Облегчённые игры для новичков (в планах)
Если игрок впервые взял дротики — отдельные упрощённые упражнения
(«Попади в мишень», «Большое кольцо», «Широкий сектор 20» и т.д.).
