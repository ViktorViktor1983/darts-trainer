Этот файл — краткая инструкция для любого ИИ (Claude, ChatGPT, Gemini и т.д.),

## 1. ПРОЕКТ

**Название:** Darts Trainer (Персональный тренер по дартсу)
**Платформа:** Android, нативный Kotlin + Jetpack Compose + Room
**Репозиторий:** github.com/ViktorViktor1983/darts-trainer (ветка main)
**Пакет:** com.lodkin.dartstrainer
**Сборка:** Gradle Kotlin DSL (build.gradle.kts)

настройки игрока, тренировки.

## 5. АРХИТЕКТУРА

### Навигация
Ручная, без Navigation Compose. Работает через переменные в MainActivity.kt:

    var stage by remember { mutableStateOf("loading") } // welcome / onboarding / loading / main
    var screen by remember { mutableStateOf("main") }   // экран внутри stage=main

Карта PARENT_SCREEN определяет, куда возвращает системная кнопка «Назад».

### Данные
Room Database. Для каждой игры — отдельная база:
Game501Database.kt, CricketDatabase.kt и т.д.
Внутри каждой: Entity, Dao, Database, Repository — всё в одном файле.

### Хранение сложных структур
Игроки и их метрики хранятся строками через разделитель «|» (по игрокам)
или «,» (внутри одного игрока). Пример: ppr = "62.14|48.30".
При чтении парсится функциями parseStringList, parseIntList, parseDoubleList.

### Стиль
Jetpack Compose, тёмная тема. Карточки — TileBg (обычная) и TileBgDark (тёмная).
Акценты — Accent, GoldAccent.

## 9. ПРОЕКТНЫЕ РЕШЕНИЯ

- 16 уровней по официальным разрядам Минспорта (Ю3 → МС) — но
  названия в x01 сделали без привязки к разрядам
  (Разрядник, Мастер, Супер мастер, Легенда).
- Уровень игрока определяется по 2 из 3 параметров:
  Сектор 20, Набор очков, Большой раунд.
  Удвоения — отдельный тренировочный приоритет, на уровень не влияют.
- Понижение уровня: если 2 из 3 параметров упали на 10 тренировках.
- Разминка 4 фазы: мышцы 2–3 мин → траектория 1–2 мин →
  кучность 1–2 мин → прицеливание.
- Структура тренировки: разминка → блок 1 (слабое место) → блок 2 →
  блок 3 (501/Крикет) → силовые (гантели 1 кг).
- Контрольная тренировка — каждая 10-я, сдача нормативов.
- Отложенные даблы возвращаются в начале следующей тренировки.
