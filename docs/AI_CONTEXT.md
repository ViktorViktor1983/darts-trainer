# AI_CONTEXT — шпаргалка для нового ИИ-ассистента

Этот файл — краткая инструкция для любого ИИ (Claude, ChatGPT, Gemini и т.д.),
который подхватит работу над проектом Darts Trainer. Прочитай целиком,
прежде чем задавать вопросы.

---

## 1. ПРОЕКТ

**Название:** Darts Trainer (Персональный тренер по дартсу)
**Платформа:** Android, нативный Kotlin + Jetpack Compose + Room
**Репозиторий:** github.com/ViktorViktor1983/darts-trainer (ветка main)
**Пакет:** com.lodkin.dartstrainer
**Сборка:** Gradle Kotlin DSL (build.gradle.kts)
**CI:** GitHub Actions — APK собирается автоматически после каждого коммита (3–5 минут)

настройки игрока, полноценный тренировочный раздел с ИИ-планировщиком,
система рекордов, сдача нормативов, свободный режим с рулеткой,
раздел «О программе».

**Автор:** Виктор Лодкин (ViktorViktor1983).

**Второе приложение (не трогаем):**
Darts Checkout — справочник чекаутов.
Репозиторий: github.com/ViktorViktor1983/DARTS-checkout

## 2. КАК ОБЩАТЬСЯ С АВТОРОМ

Автор — не программист, изучает Kotlin/Android по ходу дела.
Правила:

- Объясняй простыми словами, без жаргона.
- **ОДИН ФАЙЛ — ОДНО СООБЩЕНИЕ.** Железное правило.
- **Формат выдачи кода:**
  1. Путь к файлу в отдельном блоке кода (чтобы легко копировалось).
  2. Действие: «создать новый» / «заменить целиком».
  3. Сам код целиком одним блоком.
  4. **В САМОМ КОНЦЕ обязательно писать маркер:** `Конец файла.` (чтобы автор мог проверить, что текст не оборвался при копировании).
- Давай код **целиком**, не разбивай на части.
- **АВТОР ПРОСИТ: «путь и файл целиком» — это принципиально.**
  Даже для правки в 2 строки — давай весь файл. Так меньше шансов на ошибку.
  Не предлагать точечные правки «замени строку X» — автор так не работает.
- Если файл уже собран — не переписывай, но всё равно давай целиком.
- Автор часто присылает **скриншоты** — это нормально.
- **ВАЖНО:** сборка в GitHub Actions запускается автоматически после сохранения.
  Нельзя давать два шага в одном сообщении.
- Если автор просит «обнови AI_CONTEXT» — перепиши файл целиком.
- **НЕ использовать вложенные блоки кода (тройные бэктики внутри тройных)** —
  это ломает копирование текста.
- Автор задаёт вопросы **по одному**, отвечай так же.
- Сначала согласуй логику, потом давай код.
- Если автор прислал не тот файл — вежливо скажи и попроси нужный.
- **Автор может не понимать техническую часть** — ты решаешь, как лучше
  технически, а он задаёт логику «как должно работать». Доверяй ему в логике,
  он доверяет тебе в технике.

**Что автор УМЕЕТ:**
читать текст, скриншоты, фото; писать код Kotlin/Compose/Room
(копирует в GitHub вручную); собирать APK через GitHub Actions.

**Что автор НЕ УМЕЕТ:**
открывать ссылки/GitHub/интернет за ИИ, генерировать картинки,
загружать файлы в GitHub за ИИ.

**Что раздражает автора:**
- когда ИИ просит «найди строку X в файле» — он предпочитает получить
  файл целиком и заменить его тоже целиком;
- когда файл слишком большой (2000+ строк) — просит разбить на части;
- когда кнопка в диалоге уходит за пределы экрана.

## 5. АРХИТЕКТУРА

### Навигация (MainActivity.kt)
Ручная. var stage: welcome / onboarding / loading / main.
var screen: экран внутри stage=main.
PARENT_SCREEN — карта для системной «Назад».

### Экраны тренировки
training, training_settings, training_progress, training_warmup,
training_block, training_exercise, training_summary,
training_block_exercise, training_extra_game,
training_free_next, training_free_summary,
**normatives, normatives_exercise**.

### TRAINING_SCREENS (где таймер тренировки)
training_warmup, training_block, training_exercise,
training_block_exercise, training_extra_game, training_free_next.

### TrainingBlockPhase (enum)
WARMUP, MAIN, PSYCHOLOGY, STRENGTH, FINISHED.

### Два режима тренировки

**1. По времени** — классический. 30/45/60/80/100/120 мин.
Разминка, психология, силовая (по флагам). Автосейв, правило 3 часа.
Выход через диалог «Закончить / Отложить».

**2. Свободная (с рулеткой)** — без времени.
Все 8 упражнений доступны сразу.
Рулетка со случайным выбором. Галочка «Без повторов».
**Новое:** переключатель «Выбрать самому» — показывает список упражнений.
Автосейв не работает.

### Сдача нормативов (пятый режим)
**Доступна, когда все 8 упражнений сыграны по 5 раз (прогресс 100%).**
5 шагов: 501, Крикет, Сектор 20, Большой раунд, Набор очков.
501 и Крикет — до 3 побед (макс 5 легов).
Лестница ботов: −1, =, +1, −1, = (на краях 1/16 — все равные).
Сдал = хотя бы один комплекс дотянул до нового уровня.
После сдачи: статистика периода сбрасывается,
рекорды и чекауты сохраняются.
Экзамен считается тренировкой №1 нового периода.

### Точечная работа (Снайпер)
Если есть проблемные сектора (отклонение >25%, минимум 5 записей) и в этом периоде ещё не было упражнения `targeted_practice`, планировщик ставит его **первым**.
Берётся до 3 худших Секторов, Удвоений и Утроений (максимум 9 целей).
По 15 дротиков на каждую цель. Кнопки «Попал / Мимо».
В конце результат сохраняется в историю.

## 6. СИСТЕМА РЕКОРДОВ

### Что считается рекордом

| Игра | Рекорд |
|---|---|
| Кругосветка × 3 | Минимум дротиков (по каждому режиму) |
| Сектор 20 | Максимум очков |
| Большой раунд | Максимум очков |
| Набор очков | Максимум очков |
| 501 | Лег: мин дротиков. Матч: лучший PPR. |
| Крикет | Лег: лучший MPR. Матч: лучший MPR. |

### Где хранятся
- Старые игры — из партий.
- 501 и Крикет — training_records (тренировка)
  и free_records (свободная игра).

### Логика фиксации 501 и Крикета
Парные игры — не фиксируются. Только 1×1.
«Свой» игрок по SettingsStorage.getPlayerName().
Только выигранные леги и матчи.

### Порог «почти рекорд» ≤10%
### Форматы цифр: PPR/MPR — 1 знак, дротики — целое, % — целое.

### Закрытые чекауты
Хранятся в training_checkouts (тренировка).
Показываются по кнопке 🏆 в TrainingProgressScreen.
НЕ сбрасываются после нормативов.

### Сбросы
- Тренировочные — через TrainingSettingsScreen → clearAllTrainingData().
- Свободная игра 501/Крикет — через StatsScreen → clear501() / clearCricket().
- Полный заводской сброс — SettingsScreen.
- После сдачи нормативов — clearStatisticsAfterNormatives() (рекорды и чекауты остаются).

### Два комплекса уровня
- Комплекс 1 — упражнения (среднее 4 параметров).

- Итоговый = максимум.

### Тренды = по 3 последним тренировкам.

### Бюджет основной части
Разминка 6 / психология 8 / силовая 7 / резерв 5 минут.

### Личный темп игрока
avgMinutesByExercise — программа подстраивается под скорость.

### Мягкий старт
- Тренировки 1–2: игры + лёгкие.
- Тренировка 3: + средние.
- Тренировки 4+: всё, максимум 1 тяжёлое.
- В свободном режиме НЕ применяется (ignoreHardLimit = true).

### Таймер отдыха
3 мин лёгкие / 4 средние / 5 тяжёлые.

### Свободный режим
- Рулетка (текстовая анимация 1.5 сек).
- Галочка «Без повторов».
- **Галочка «Выбрать самому»** (список упражнений).
- Все 8 упражнений.
- Автосейв не работает, правило 3 часа не применяется.

### Сдача нормативов
- 5 шагов, лестница ботов.
- 501 и Крикет до 3 побед (макс 5 легов).
- Сдал — новый уровень, статистика сбрасывается.
- Не сдал — уровень подтверждён, статистика остаётся.
- Открывается по шкале прогресса (по 5 записей на каждое упражнение).
