## 5. АРХИТЕКТУРА И ЛОГИКА

### Периоды
С момента последнего экзамена. При сдаче экзамена (`clearStatisticsAfterNormatives`) данные не удаляются, а начинается новый период (`periodId + 1`).

### Статистика
Собирается в `detailsJson`. В `DisciplineStatsScreen` строятся графики.
**Проблемные сектора:** После 5 Кругосветок программа подсвечивает сектора (желтым/красным), где точность ниже средней.

### Тренировка (НОВАЯ ЛОГИКА)
1. **Порядок блоков:** Разминка ➔ Психология ➔ Основной блок ➔ Силовой блок ➔ Итоги.
2. **Таймер:** Идет в обратном порядке.
3. **Окно за 5 минут:** Когда остается 5 минут, выскакивает `TimeUpDialog` с кнопками «К силовым» и «Доиграть».
4. **Таймер в минус:** Если игрок нажимает «Доиграть», таймер уходит в минус (например, `-01:15`). Игрок может запускать новые игры бесконечно.
5. **Экран итогов:** Кнопка «ПЕРЕЙТИ К СЛЕДУЮЩЕМУ БЛОКУ» переводит на следующий блок (или завершает тренировку).
6. **Свободные игры:** Игрок может играть в любые игры из списка "Рекомендовано сыграть" прямо с экрана итогов.

### Психология и Силовые
- **Психология:** 8 упражнений. Даются по 3 штуки.
- **Силовые:** 9 упражнений. При входе в блок выскакивает `InventoryDialog` (выбор гантелей/резинки).

### Онлайн-игра (Бэклог)
Решено делать через **Firebase** (Firestore + FCM).
- Матчмейкинг: поиск соперника с похожим уровнем.
- Синхронизация: Броски и счет в реальном времени (Snapshot Listeners).
- Уведомления: Push через Firebase Cloud Messaging.
