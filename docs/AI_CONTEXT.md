Этот файл — краткая инструкция для любого ИИ (Claude, ChatGPT, Gemini и т.д.),
который подхватит работу над проектом Darts Trainer. Прочитай целиком,
прежде чем задавать вопросы.

## 1. ПРОЕКТ

**Название:** Darts Trainer (Персональный тренер по дартсу)
**Платформа:** Android, нативный Kotlin + Jetpack Compose + Room
**Репозиторий:** github.com/ViktorViktor1983/darts-trainer (ветка main)
**Пакет:** com.lodkin.dartstrainer
**Сборка:** Gradle Kotlin DSL (build.gradle.kts)
**CI:** GitHub Actions — APK собирается автоматически после каждого коммита (3–5 минут)

Приложение для игры в дартс с ботами. 6 игровых режимов, статистика,
настройки игрока, полноценный тренировочный раздел с ИИ-планировщиком,
система рекордов, сдача нормативов, свободный режим с рулеткой,
раздел «О программе», а также **полноценный онлайн-режим для 501**.

**Автор:** Виктор Лодкин (ViktorViktor1983).

**Второе приложение (не трогаем):**
Darts Checkout — справочник чекаутов.
Репозиторий: github.com/ViktorViktor1983/DARTS-checkout

## 5. АРХИТЕКТУРА И ЛОГИКА

### Онлайн-игра (501)
- **Полный цикл**: Регистрация -> Поиск (Broadcast или Друг) -> Приглашение -> Булл -> Игра 501 -> Чат -> Завершение.
- **Синхронизация**: `Game501Screen.kt` отправляет состояние (JSON) на сервер при каждом изменении счета, и читает состояние соперника каждые 1.5 секунды.
- **Защита от зависаний**: Флаг `isSendingMove` блокирует чтение на 0.8 секунды во время отправки хода.
- **Защита от отката**: Телефон принимает стейт, только если количество сетов/легов/дротиков у соперника не меньше, чем локально.
- **Кнопка Undo**: Работает в онлайне. Возвращает ход, очки и отправляет исправленный стейт.
- **Булл**: Реализован на экране игры. Кнопки «Мимо» (серая), «Зеленый», «Красный». Автостарт через 2 секунды.
- **Чат**: Сообщения отправляются в базу `messages` и читаются каждые 2.5 секунды.
- **Друзья**: Локальный список. В окне приглашения есть кнопка «Список друзей» (выпадающее меню с корзинами для удаления).

### Онлайн-игра (Крикет)
- **НЕ СИНХРОНИЗИРУЕТСЯ.** Сейчас при запуске по сети играет локально с ботом.

### Тренировка, Статистика, Экзамен
- Без глобальных изменений (см. старые версии контекста, если нужно).
