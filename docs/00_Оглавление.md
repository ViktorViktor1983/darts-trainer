# Оглавление проекта Darts Trainer

Вся проектная документация по приложению-тренеру по дартсу.

## Список документов

| № | Файл | О чём |
|---|---|---|
| 00 | Оглавление | Этот файл |
| 01 | Концепция | Суть приложения, для кого, чем отличается |
| 02 | Анкета | Что спрашиваем при первом запуске |
| 03 | Режимы тренировок | 3 режима с плюсами и минусами |
| 04 | Структура тренировки | Разминка → блоки → силовые |
| 05 | Уровни и разряды | 16 уровней по официальным нормативам |
| 06 | Удвоения | Логика блока, отложенные даблы |
| 07 | Набор очков | Сектор 20, 19, 18, Набор очков |
| 08 | Сектора | Большой раунд, Раунды сектор |
| 09 | Чекауты | Тренировка закрытий 2–170 |
| 10 | Силовые | Упражнения с гантелями и эспандером |
| 11 | Свободная игра | «Просто поиграть» без программы |
| 12 | Статистика | Что показывает профиль |
| 13 | Подсказки | «Зачем это нужно» + психология + завершение |
| 14 | Тестирование | План с 3–5 тестировщиками |
| 15 | План разработки | Этапы, сроки |
| 16 | Контрольная тренировка | Каждая 10-я — сдача нормативов |
| 17 | Психология | Дартит, рутина, страх даблов, упражнения |
| 18 | Разминка | Система разминки из 4 шагов |

## Что где искать

### Для разработчика
- **01, 15** — общая картина и план.
- **05** — уровни и пороги.
- **02, 03, 04** — структура приложения.

### Для логики тренировок
- **04** — структура тренировки.
- **06–10** — блоки программы.
- **16** — контрольная тренировка.

### Для UX и мотивации
- **11** — свободная игра.
- **12** — статистика.
- **13** — подсказки.
- **17** — психология.
- **18** — разминка.

## Статус

Документация в процессе наполнения. По мере обсуждения файлы дополняются.
