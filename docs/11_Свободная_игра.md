# 11. Свободная игра

Иногда игрок не хочет тренироваться по программе — хочет просто поиграть в своё удовольствие. Приложение даёт такую возможность.

## Как работает

### Экран выбора при запуске

При запуске приложение спрашивает:

- Тренировка — по программе тренера
- Просто поиграть — свободная игра

## Если выбрано «Просто поиграть»

### Второй вопрос

Приложение спрашивает: «Заносить результаты в статистику?»

Варианты:
- Да, учитывать
- Нет, просто поиграл

### Почему спрашиваем

- Иногда играешь уставший — результат плохой. Не хочется, чтобы это портило статистику тренировок.
- Иногда просто разминаешься или пробуешь новые дротики.
- Иногда играешь с друзьями в баре — это не «тренировка».

## Доступные игры

Все игры, которые есть в приложении:
- 501 (против бота или с другом на одном устройстве)
- Американский крикет
- Раунды (удвоения, утроения, сектор)
- Большой раунд
- Сектор 20, Сектор 19, Набор очков
- Чекауты

Свобода выбора — играй что хочешь.

## Две отдельные статистики

### Тренировки

- Влияют на уровень, программу, разряды.
- Анализируются приложением.
- Учитываются в общей картине прогресса.

### Свободные игры

- Не смешиваются с тренировками.
- Только для информации и удовольствия.
- Показываются отдельным разделом.

### Экран статистики

Раздел «Тренировки»:
- Средний набор: 55
- Удвоения: 25%
- Уровень: 8

Раздел «Свободные игры»:
- Средний набор: 62
- Побед: 15 из 22

## Приложение сообщает игроку

При выборе «Просто поиграть» + «Заносить в статистику» приложение пишет:

Результаты этой игры пойдут в раздел «Свободные игры». Они не влияют на тренировочную программу и уровень.

## Если игрок показывает хороший результат

Приложение может мягко предложить (не навязывая):

- «У тебя сегодня отличный набор — 65. Хочешь, тренер подстроит программу под этот уровень?»
- «Заметили слабое место — даблы. Может, включить их в следующую тренировку?»

Без давления. Просто предложение.

## Силовые при свободной игре

Если игрок выбрал «Просто поиграть» после завершения тренировки:

- Сначала делаем силовые.
- Потом переходим в свободную игру.

Мышцы нужно укреплять всегда, даже в дни свободной игры.

## Напоминание о тренировке

Если игрок часто выбирает «Просто поиграть», а по программе у него тренировка:

- Мягкое напоминание: «Сегодня по плану тренировка. Но если хочешь просто поиграть — без проблем. Главное — играй!»

Без давления. Приложение уважает выбор игрока.

## Что важно

- Свобода выбора. Не заставляем тренироваться всегда.
- Честность. Отдельная статистика — не смешивается с тренировками.
- Мотивация без давления. Мягкие предложения, а не приказы.
- Силовые всегда. Даже в свободной игре — для выносливости.
