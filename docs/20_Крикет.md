# 20. Крикет

Второй игровой режим после 501. Проще по структуре — хорош для «набивки руки» перед более сложными режимами.

## Режимы игры

Четыре варианта:
1. Игрок против игрока.
2. Игрок против бота.
3. Пара против пары игроков.
4. Пара против пары ботов.

## Типы крикета

### Американский (с очками)

Классический крикет. Цель — закрыть все сектора и набрать больше очков.

**Сектора:** 15, 16, 17, 18, 19, 20, Bull.

**Закрытие сектора:**
- Попадание S = 1 раз.
- Попадание D = 2 раза.
- Попадание T = 3 раза.
- Три попадания → сектор закрыт.

**Очки:**
- Если сектор закрыт у тебя, но не закрыт у соперника — набираешь очки.
- S = 1× номинала, D = 2×, T = 3×.
- Bull = 25 (зелёное кольцо) или 50 (красный центр).

**Победа:**
- Все сектора закрыты у обоих игроков.
- У кого больше очков — тот победил.

### Без набора очков

То же самое, но очки не считаются. Цель — закрыть все сектора быстрее соперника.

Подходит для быстрых партий.

## Экран настройки партии

- **Игроки:** 2 слота (для парной — 4).
- **Парная игра:** тумблер.
- **Тип крикета:** Американский / Без набора очков.
- **Игра с ботом:** тумблер.
- **АвтоОК:** настраивается (3 / 5 / 10 секунд или выкл).
- **Очистить историю.**

## Боты с именами

Не «Бот 1–16», а имена с диапазоном среднего набора. Своя система, привязана к уровням.

| Имя бота | Диапазон среднего набора |
|---|---|
| Новичок | 15–19 |
| Ученик | 18–22 |
| Любитель | 21–25 |
| Уверенный | 25–30 |
| Разрядник | 30–38 |
| Сильный | 38–50 |
| Чемпион | 50+ |

В списке — имя + диапазон. Например: «Любитель (21–25)».

## Экран игры

### Верхняя панель

- Имена игроков (слева и справа).
- Счёт легов (в центре).
- Средний набор — под именем каждого игрока.
- Метка активного игрока (точка рядом с именем).

### Таблица секторов

По центру — вертикальный список:

20
19
18
17
16
15
Bull

**Для каждого сектора — три кнопки ввода:**
- **T** — утроение (3 попадания).
- **S** — сектор (1 попадание).
- **D** — удвоение (2 попадания).

Кнопки слева и справа от номера сектора — по одной на каждого игрока.

### Визуализация попаданий

Под каждой кнопкой T/S/D — ячейка с прогрессом:

- **Пусто** — 0 попаданий.
- **Слэш `/`** — 1 попадание.
- **Крестик `✕`** — 2 попадания.
- **Жирный крестик** — 3 попадания (сектор закрыт).
- **Цифры рядом** — количество очков в этом секторе.

У Viktor: у сектора 20 — жирный крестик (закрыт), у сектора 19 — крестик (2 попадания), очки видны рядом.

### Табло над секторами

Показывает текущие очки игроков и средний набор.

### Кнопка «Вернуть ход назад»

Позволяет отменить последнее действие. Перед отменой — подтверждение:

«Вернуть ход назад?» → [НЕТ] [ДА]

## Ввод попаданий

### Основной способ

Игрок нажимает кнопку **T / S / D** у нужного сектора. Приложение автоматически:
- Добавляет попадание в прогресс сектора.
- Начисляет очки (если нужно).
- Проверяет, не закрыт ли сектор.
- Передаёт ход сопернику.

### Если промах

Отдельной кнопки «промах» нет. Игрок просто **не нажимает** никакую кнопку — ход передаётся автоматически или вручную.

## Парная игра

### Отображение

- **Команда 1:** 2 столбца слева (игрок 1, игрок 2).
- **Команда 2:** 2 столбца справа (игрок 3, игрок 4).

Все 4 игрока видны одновременно. Прогресс секторов — у каждого свой.

## Диалоги

### При победе в леге

«Сколько дротиков ушло на закрытие лега?»

Варианты: 1 / 2 / 3 / Отмена.

### При отмене хода

«Вернуть ход назад?» → [НЕТ] [ДА].

## Статистика после матча

### Основные показатели

- **Средний набор** за матч.
- **Процент попаданий** в T20, T19, T18.
- **Среднее дротиков на закрытие сектора.**
- **Промахи по секторам** — куда целился, но не попал.

### По секторам

Таблица с детализацией:
- Сектор 20: попаданий X, очков Y.
- Сектор 19: попаданий X, очков Y.
- ...
- Bull: попаданий X, очков Y.

### Наше уникальное

- **Слабые сектора** — где промахов больше всего.
- **Прогресс** — сравнение с прошлыми матчами.

## Что берём из чужих приложений

- Структура таблицы: сектора в центре, игроки по бокам.
- Кнопки T / S / D для ввода.
- Визуализация попаданий: слэш, крестик, жирный крестик.
- Два типа крикета: с очками и без.
- Парная игра.
- Боты с диапазонами.
- Диалог «дротиков на закрытие».
- Кнопка «Вернуть ход назад».

## Что делаем по-своему

- Тёмная тема (как в нашем приложении).
- Голубой акцент + золотой для очков.
- Крупные шрифты для читаемости.
- Расширенная статистика: % попаданий по секторам, слабые сектора.
- Боты привязаны к нашим уровням с именами.

## Что НЕ используем

- Кнопку «промах» — не нужна, ход передаётся без нажатия.
- Слишком плотную таблицу — сделаем крупнее и читаемее.
- Копирование цветовой гаммы.

## Важно

- **Крикет — тренировочный режим для руки.** Проще 501, помогает освоиться с вводом.
- **Все данные сохраняются** в Room для статистики.
- **Будут итерации.** После тестирования что-то уберём, что-то добавим.
