# 15. План разработки

Этапы разработки приложения Darts Trainer — от проекта до публикации.

## Этапы

### Этап 1. Базовая основа

- Создание Android-проекта (Kotlin + Compose).
- Настройка GitHub Actions для сборки.
- Тёмная тема, цвета, базовые компоненты.
- Главный экран с кнопками «Тренировка» / «Просто поиграть».
- Анкета при первом запуске.

**Результат:** приложение запускается, показывает главный экран и анкету.

### Этап 2. Игровая логика 501

- Игра 501 против бота.
- Ввод дротиков (T20, S19, D5) — как в Darts Checkout.
- Расчёт очков, «бюст», double-out.
- Простой бот (3–5 уровней сложности).
- Сохранение результатов.

**Результат:** можно играть партию против бота.

### Этап 3. Тренировочные упражнения

- Раунды на удвоения (D1–D20 + Bull).
- Большой раунд.
- Сектор 20 / 19 / 18.
- Набор очков.
- Американский крикет.

**Результат:** все основные упражнения доступны.

### Этап 4. Программа тренировок

- Логика определения слабого места (2 из 3).
- Формирование программы на день.
- Структура: разминка → блоки → силовые.
- Подсказки «зачем это нужно».

**Результат:** приложение само строит программу.

### Этап 5. Статистика и уровни

- Сохранение всех результатов.
- Расчёт параметров (набор, удвоения, точность).
- 16 уровней по официальным нормативам.
- Поздравления и понижения.
- Экран профиля со статистикой.

**Результат:** игрок видит свой прогресс.

### Этап 6. Дополнительно

- Чекауты (тренировка закрытий 2–170).
- Силовые упражнения.
- Свободная игра («просто поиграть»).
- Отложенные даблы.
- Достижения.

**Результат:** полный функционал.

### Этап 7. Тестирование

- Сбор 3–5 тестировщиков в дартс-клубе.
- 2–4 недели реального использования.
- Сбор отзывов и багов.
- Исправления.

**Результат:** отполированное приложение.

### Этап 8. Публикация

- Создание иконки.
- Скриншоты.
- Описание для RuStore.
- Релизная сборка APK.
- Публикация в RuStore.

**Результат:** приложение в магазине.

## Сроки

Реалистичная оценка — 2–3 месяца при работе в свободном темпе.

- Этап 1: 1–2 недели.
- Этап 2: 2–3 недели.
- Этап 3: 2 недели.
- Этап 4: 2 недели.
- Этап 5: 2–3 недели.
- Этап 6: 2–3 недели.
- Этап 7: 2–4 недели (тестирование).
- Этап 8: 1 неделя.

## Технический стек

- **Kotlin** — язык.
- **Jetpack Compose** — интерфейс.
- **Room** — база данных (тренировки, статистика, настройки).
- **SharedPreferences** — простые галочки (подсказки, сортировка).
- **Coroutines + Flow** — асинхронность.
- **GitHub Actions** — сборка APK.

## Архитектура

- **MVVM** — ViewModel + StateFlow.
- Разделение на слои: data / domain / ui.
- Каждый экран — отдельный файл.
- Компоненты — отдельно (кнопки, карточки, диалоги).

## Что НЕ используем

- Сервер — не нужен, всё локально.
- Аккаунты — не нужны.
- Firebase — не нужен.
- WebRTC — не нужен (это в другой идее).

## Хранение данных

- **Room** — тренировки, результаты упражнений, статистика по секторам и даблам.
- **SharedPreferences** — галочки «не показывать», режим тренировок, имя игрока.

## Репозиторий

Код будет в этом же репозитории `darts-trainer`. Структура:

- `docs/` — проектная документация (эта папка).
- `app/` — код приложения (будет позже).

## Связь с Darts Checkout

Darts Trainer — **отдельное приложение**. Оно использует идею чекаутов, но:
- Darts Checkout — справочник закрытий.
- Darts Trainer — персональный тренер с программой.

Функция «Закрытые чекауты» из Darts Checkout может быть перенесена в Darts Trainer как часть блока чекаутов.

## Уровни готовности
