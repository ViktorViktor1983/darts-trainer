# 08. Блок «Работа по секторам»

Этот блок тренирует точность попадания в сектор. Упражнения: Большой раунд и Раунды режим сектор.

## Большой раунд

### Как играть

- 3 дротика в каждый сектор по порядку: 1, 2, 3, ..., 20, Bull.
- Цель — попасть в утроение сектора.
- Очки считаются как в «Дартс базе»: S = 1, D = 2, T = 3. Промах = 0.
- Сумма за все 21 цель — итоговый результат.

### Что даёт

- Статистику по каждому сектору.
- Точность в утроения (набор очков).
- Материал для анализа слабых секторов.

### Роль в тренировке

Большой раунд — регулярно, через тренировку. Он и тренировка, и сбор статистики. Через 3–4 Больших раунда приложение видит, какие сектора хромают.

## Раунды режим сектор

### Как играть

- Цели по порядку: S1, S2, ..., S20 (без Bull).
- Нужно попасть 1 раз в целевой сектор.
- Пока не попадёшь — цель не меняется.
- Считается общее количество дротиков.

### Роль в тренировке

Точечная тренировка слабого сектора. Когда по статистике Большого раунда видно, что конкретный сектор хромает — запускаем на него «Раунды режим сектор».

## Логика блока

1. Большой раунд — регулярно (через тренировку).
2. Анализ — через 3–4 Больших раунда.
3. «Раунды режим сектор» — точечно на слабый сектор.

## Анализ слабых секторов

### Как определять

После каждого Большого раунда сохраняется статистика по секторам:
- Сектор 1: 3 очка
- Сектор 2: 5 очков
- ...
- Сектор 13: 7 очков (сильный)
- Сектор 20: 1 очко (слабый)

### Что считается «слабым»

Сектор, где средний результат ниже ожидаемого для уровня игрока.

Например, для уровня 3 (Большой раунд = 420–435):
- Средний на сектор = 420 / 21 = 20.
- Сектор 20 даёт в 3 раза больше, чем сектор 1 (потому что очки = попадания × номер).
- Значит, для сектора 1 норма — около 3–4, для сектора 20 — около 6–7.

Точные пороги для каждого сектора определим позже, исходя из уровня.

## Когда блок запускается

### Вариант А. Регулярно

Большой раунд идёт всё время, через тренировку. Точечные «Раунды сектор» — только когда есть слабый сектор.

### Вариант Б. По расписанию

Один раз в неделю — обязательный Большой раунд.

### Моя рекомендация

Вариант А. Большой раунд — в ротации между тренировками. Если по статистике всё в норме — только Большой раунд. Если есть слабый сектор — добавляем «Раунды сектор».

## Пример структуры блока

### Тренировка 1 (сбор статистики)

- Большой раунд — полный цикл (21 сектор)

### Тренировка 2 (если найден слабый сектор)

- Большой раунд — полный цикл
- Раунды режим сектор — точечно на слабый

### Если всё в норме

- Большой раунд — полный цикл

## Связь с другими блоками

- Набор очков — Большой раунд тренирует и набор (через T20).
- Удвоения — Большой раунд НЕ тренирует даблы (игрок целится в утроения).
- Точность — основной фокус блока.

## Статистика

### Что считается

- Общий результат Большого раунда.
- Разбивка по секторам (очки за каждый).
- Слабые сектора — список.

### Отображение в профиле

- Общий результат за последний Большой раунд.
- Сравнение с порогом уровня.
- График за месяц.
- Топ-3 слабых сектора.

### История

Все Большие раунды сохраняются. Можно посмотреть, как менялся результат по неделям.

## Что важно

- Большой раунд — не про даблы. Игрок целится в утроения. Специально в дабл никто не кидает.
- Если с сектором совсем плохо — добавляем точечную тренировку «Раунды сектор».
- Не зацикливаемся на слабом секторе — если он не поддаётся месяц, откладываем и возвращаемся позже.
