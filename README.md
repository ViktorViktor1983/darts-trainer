# Darts Trainer

Персональный тренер по дартсу — приложение, которое ведёт игрока по программе тренировок, анализирует слабые места и помогает расти от новичка до мастера спорта.

## Что это

Не справочник и не игра, а **личный тренер в кармане**:

- Составляет программу на каждую тренировку под конкретного игрока.
- Анализирует три параметра: **набор очков**, **удвоения**, **точность**.
- Даёт упражнения на слабые места.
- Ведёт статистику и присваивает уровни (по официальным разрядам).
- Мотивирует: поздравления, достижения, прогресс-бары.

## Для кого

- **Новичкам** — чтобы понять, с чего начать, и не бросить через неделю.
- **Любителям** — чтобы системно расти, а не тренироваться хаотично.
- **Разрядникам** — чтобы подтянуть слабые места и выступать стабильнее.
- **Тренерам** — как инструмент для работы с учениками.
